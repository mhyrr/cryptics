### Traps we now know about (from the cipher work)

1. **"Mis-catalogued" is not "unknown."** fr. 15561 f. 42 is filed only as "Règne de Henri III", but Tomokiyo had
   already rebuilt a key from it. Before calling anything new, check cryptiana, DECODE, and the GitHub repos of other
   readers (cabinet-noir, pangoleen). Novelty is in the reading, not in the finding.
2. **Two readers agreeing is not accuracy.** On the Borja crib, Sonnet readers scored 86% precision but only about 63%
   recall, and on f. 174 the two readers shared the same misreadings of base signs. Each cipher series needs an external
   crib (a period decipherment, a duplicate, a Simancas minute) before a reading counts.
3. **Archives block scripts.** Gallica returns 403, PARES 429, the Morgan 403, and the BL had restored only about 1,000 of
   its 4,500+ digitized manuscripts at the last report found (Oct 2024). Plan for browser screenshots at human speed. That, not compute, sets the cost.
4. **The page itself can defeat the reader.** Show-through on f. 213 broke four readers. A per-reader notation
   normaliser fixed swapped vowel marks only because its controls were frozen first. Without frozen controls, a
   normaliser fits noise.
5. **Look in the recipient's papers, not the sender's.** Letters received at Simancas were usually deciphered on
   arrival. The unread ones are the King's outgoing letters in ambassadors' papers that ended up abroad: BnF Espagnol,
   the Morgan, Gondomar's papers.

## 1. Audit of the scoring (`rank.py`)

`composite = 2×verifier + gap + data_ready + cheapness + payoff` (max 30). Ethics is shown as a flag; crowding is
parsed but not used. Concrete defects:

1. **No novelty-to-the-world axis.** `gap` asks whether anyone swept the data. It does not ask whether a confirmed hit
   is already known to specialists. Rated by that question, 05#1 scored gap 4, and its one real-world hit (fr. 15561
   f. 42) was already in Tomokiyo's pages. `payoff` mixes "important" with "new", so a small result that is certainly
   new (an OEIS counterexample) ranks below a big result that is probably known.
2. **No "already demonstrated" signal.** Two candidates have confirmed hits in this repo (OEIS: 3 counterexamples; es. 132
   letters: six folios first read in one day). The formula treats them the same as untested ideas. An observed hit rate is
   the best evidence the survey has, and it is ignored.
3. **Crowding is not scored, and is parsed badly.** The script takes the first `OPEN/PARTLY/CROWDED` word anywhere in
   the section. That labels fan fiction (06#9) `OPEN` and 03#10 `?`. `CROWDED` items such as Erdős (06#2, rank 10)
   and TESS (02#2) get no penalty.
4. **Ethics is only a flag.** Items with ethics_clear 2 still rank in the middle (03#9 at 37, 01#1 at 43). The README's
   ethics protocol says some of these should not be run as framed. Ethics ≤ 2 should take an item out of the ranking,
   not just mark it.
5. **"Data ready" means "public", not "reachable".** Gallica, PARES, the Morgan, the BL and loc.gov are public, but a
   script cannot use them from here. Browser-only access changes both cost and feasibility. Add an `access` axis:
   5 = bulk or scriptable; 4 = API with a key; 3 = browser only; 2 = ordered copies or a site visit; 1 = not digitized.
6. **Additive scores let easy axes buy out hard ones.** Five points of `cheapness` and `data_ready` make up for a weak
   verifier or a weak payoff. Those axes also overlap with each other. A find needs every condition to hold, so the
   score should multiply, or at least gate on a minimum.
7. **One verifier score hides two checks.** *Is it correct?* (a mechanical check, an orbit fit, a crib) and *Is it
   new?* (a literature and registry check) are different questions. The cipher work also showed that a correctness
   check depends on the quality of its input: the same verifier scores 5 on a clean page and fails on f. 213.
8. **The scores were never calibrated.** Eight agents scored on their own 1–5 scales, mostly from search snippets
   (README note). Rule 7 asks for calibration against solved cases, and none was done. A shared anchor set (e.g. "Mary
   Stuart letters before 2023 = gap 5, novelty 5") would make the files comparable.
9. **Fragile parse.** The axis regex takes the first `axis N` match anywhere in a section, and the file glob `0*.md`
   picks up every file in the directory, this one included. Tightening the regex to the `**Scores**` line would fix
   the first problem.

**Proposed revision (described, not implemented):**

```
excluded if ethics_clear <= 2
P_correct = (verifier_correct + min(access, data_ready)) / 10
P_new     = (gap + novelty) / 10
value     = payoff
cost_pen  = (5 - cheapness) * 0.5
crowd_pen = {OPEN: 0, PARTLY: 1, CROWDED: 3}   # from the Crowding field only
demo      = {none: 0, hit in repo: +2, hit reproduced by a third check or accepted externally: +3}
score     = 20 * P_correct * P_new + 2 * value - cost_pen - crowd_pen + demo
```

Adding three fields to the survey format (`novelty`, `access`, `demonstrated`) and reading crowding from the Crowding
bullet would be enough. Under this formula, 06#1 and 09#1 come first, 05#1 falls out of the top 10, and 04#1 stays
high (with lower certainty, because its access is blocked).

### 2. Philip IV to the Marquis de Velada, ambassador in England, 1636–1641 (Morgan Library)

A second Morgan record holds two cipher copies of letters of 17 Dec 1640 to the Cardinal-Infante Fernando, meant for his ambassadors in England. Images: unknown (the Morgan site returned 403 to this machine).

### 7. Monasterium.net: charter images with no transcription

- **Data:** Monasterium.net (ICARUS), a virtual archive of more than 650,000 mainly medieval and early modern charters from over 100 institutions. A 2012 snapshot gave about 250,000 documents and 387,000 images, with full text for only about 22,000.
- **Question / what a find looks like:** a charter with only an abstract, transcribed for the first time and found to contain an unrecorded person, place or event, or a forgery.
- **Gap evidence:** the 2012 ratio of text to images; no current breakdown found.
- **Verifier:** weak. The abstracts give a check on date and parties; the text itself is formulaic; a Latinist has to judge it.
- **Precedent:** none of this kind found.
- **Recipe:** HTR of untranscribed charters → compare entities against the abstracts → flag mismatches.
- **Cost:** moderate (HTR).
- **Traps:** formulae make every charter look alike; abstracts are often good, so little is really new; the payoff is diffuse.
- **Crowding:** `PARTLY` (ICARUS and partner archives).

## Leads checked and set aside (walls named)

- **Venice, Archivio di Stato, *Dispacci degli ambasciatori*:** no bulk online digitization found; the printed index
