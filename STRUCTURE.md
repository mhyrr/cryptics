## A deep dive: `puzzles/<slug>/`

The slug matches the catalog entry's slug. Files by durability class, the
same discipline as a research notebook:

| File | Holds | Behavior |
|---|---|---|
| `README.md` | one-paragraph brief, current status line, the "what a solution would have to do" criteria copied from the catalog entry and sharpened | rewritten as understanding improves |
| `canon.md` | what we believe **now** about the text: facts with a confidence and a source pointer. No story, no speculation. | rewritten as truth changes; refuted items move to `research.md` Dead ends |
| `hypotheses.md` | every hypothesis, numbered `H1…`, with status (`open` / `supported` / `weakened` / `refuted` / `superseded`), the test that would move it, and pointers to the `research.md` entries and `analysis/` runs that bear on it | rewritten; refuted hypotheses stay listed |
| `research.md` | dated `## YYYY-MM-DD` session notes, newest first, plus a `## Dead ends` section. How we learned what we know. | **append-only** |
| `NEXT.md` | the handoff: where the last session stopped, what to do first, the named wall if there is one | rewritten at every session close |
| `sources/` | curated transcriptions, editions, images, each with a `PROVENANCE.md` line saying where it came from and what was changed. `sources/cache/` is gitignored. | curated |
| `analysis/` | scripts and their checked-in outputs. One subfolder per experiment, `analysis/NN-short-name/` with a `README.md` stating the question, the method, and the result. Heavy outputs go in `out/` (gitignored) with a summary checked in. | append-only by experiment; a superseded experiment gets a note, not a deletion |

The deciding question when you learn something: *is this true, or is this how
I learned it is true, or is this what I now suspect?* True → `canon.md`. How
I learned it → `research.md`. Suspect → `hypotheses.md`.

## Slugs

Lowercase kebab-case, the commonly cited name: `voynich-manuscript`,
`wulf-and-eadwacer`, `derveni-papyrus`. The catalog entry, the puzzle folder,
and the HIVE ticket tag all use the same slug.

## Sources tiering

Everywhere a source is cited: `PRIMARY` (the object, a facsimile, a critical
edition), `SCHOLARLY` (peer-reviewed or academic press), `SECONDARY`
(encyclopedic), `CLAIMANT` (a proposed solution written by its proposer),
`POPULAR` (journalism, blogs). Claimant sources are welcome and necessary; they
are just labeled.
