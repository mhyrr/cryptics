# puzzles/

One folder per deep dive. Open one with `/focus <slug>`; the command copies
`_template/` and links the catalog entry. See `STRUCTURE.md` for the file
roles. The rule that matters: a session that does not end by rewriting
`NEXT.md` has thrown away its own work.

Active and past dives are listed in `NEXT-SESSION.md` at the repo root.
