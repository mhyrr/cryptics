# 01 — Mathers structure and conditional completion

## Question
What survives of elementary symmetry in the digital Mathers transmission, and
can simple rules determine the missing letters?

## Result
See [RESULTS.md](RESULTS.md). The export contains 242 records; 232 can be analyzed
without layout guesses (81 complete, 151 incomplete). Ten are preserved but
excluded. Transpose symmetry holds in 69 complete grids, and transpose plus
half-turn in 55. None fits the tested cyclic or alphabet-arithmetic generators.
The combined symmetry condition forces 1,064 blank cells across 111 compatible
incomplete grids. These are conditional fills, not recovered manuscript readings.

For MAIAM (25/3), four free letter orbits survive even after the symmetry fills:
456,976 A–Z completions remain. Symmetry describes constraints, not the choice of
every letter. No claim of novelty, meaningful language, or historical noise.

## Input and extraction
- `../../sources/mathers-web-rows.txt` pins Mathers-labelled row strings exported
  by the web tool from [Peterson's digital edition](https://www.esotericarchives.com/abramelin/abramelin.htm)
  on 2026-09-16 (PRIMARY text, mediated digital transcription).
- The capture covers the numbered tables in Book III, chapters 1–30. Only lines
  beginning with a square label were retained. Merged lines were preserved.
  Modern variants after `| D:` and colon-labelled German additions 10/6 and 10/7
  were omitted. Overlapping fetched lines were checked for agreement.
- `extract.py` splits merged numbered records, trims delimiter whitespace, and
  maps dots to null. It never fills ragged rows, changes letters, merges I/J or
  U/V, or promotes lowercase annotation letters to ordinary cells.
- Source 25/4 appears among chapter 24 records. Its literal label is retained
  and flagged. Footnote markers and raw rows remain available in the JSON.
- **Scope limit:** this is not a direct HTML-table scrape or a facsimile-checked
  transcription of the 1898 print. The web export adds a transcription layer.
  Captions, cell typography and ruling are not reconstructed. Source errors and
  web-extraction errors cannot yet be distinguished.

## Method
Families were declared in the dive README before computing the corpus results.
Test transpose, anti-transpose, half-turn, horizontal and vertical reflections,
and the group generated by transpose and half-turn. A symmetry orbit with two
different observed letters rejects that whole-grid family. A single observed
letter forces blank cells in its orbit; an orbit with no observed letter remains
free. No majority vote or editorial correction is applied. Local nonconflicting
fills in a rejected grid remain in the audit, but are not frozen as predictions.

On complete grids, test `grid[r,c] = first_row[(c+k*r) mod n]` for all `k`.
Also test the weaker condition that each row is any rotation of the first row.
For alphabet arithmetic, fix A=0 through Z=25, and test the interior against
`a + sr*(grid[r,0]-a) + sc*(grid[0,c]-a) mod 26`, where `a=grid[0,0]`
and each of `sr, sc` is +1 or -1. These are finite families, not an exhaustive
search over possible historical generators or alphabet encodings.

After characterization, a diagnostic masks each complete grid to just its top
row and left column. It applies fixed symmetry rules without filtering on the
hidden answers. Rejected grids count as abstentions. It compares predictions
with the most frequent visible letter on exactly the same target cells
(alphabetical tie-break). This artificial missingness test uses the same digital
transmission and is not cross-witness validation. It selects no winning rule.

Letter frequencies are raw counts, not claims of anomaly. Repeated grids are
not independent observations. No hypothesis significance test is attempted.

## Run from repository root
Python 3.11+ standard library only; no network or installed packages required.

```sh
python3 puzzles/book-of-abramelin-squares/analysis/01-mathers-structure/extract.py
python3 puzzles/book-of-abramelin-squares/analysis/01-mathers-structure/analyze.py puzzles/book-of-abramelin-squares/sources/mathers-squares.json --output puzzles/book-of-abramelin-squares/analysis/01-mathers-structure/results.json
python3 puzzles/book-of-abramelin-squares/analysis/01-mathers-structure/report.py
python3 -m unittest discover -s puzzles/book-of-abramelin-squares/analysis/01-mathers-structure -v
```

`results.json` contains counts, per-grid conflicts, free orbits and all conditional
fills. `predictions.json` freezes only compatible incomplete grids under the
combined symmetry assumption and carries input hashes. Coordinates are zero-based.
`RESULTS.md` is generated; do not hand-edit it. Tests cover an established SATOR
grid, unresolved center, conflicts, malformed inputs, generator corruption,
merged source labels and a wrong masked prediction that must count as wrong.

## Validation wall
No uncorrected German image readings have been compared. Peterson's German
variants and examples from Kollatsch's 2024 draft appeared during source
discovery. **Do not claim a blind test against those already-exposed cells.**
The source corpus does not import them, but research exposure is still exposure.
Future validation must separate new targets, editorial conjectures and shared
textual ancestry. The ten layout exclusions require facsimile inspection first.

Bears on H1–H4; see `../../hypotheses.md` for bounded statuses.
