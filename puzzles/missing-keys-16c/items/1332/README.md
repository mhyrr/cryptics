# No. 1332 — Ferdinand I to Giovanni Battista Castaldo, 1552

**Gate: out.** Two groups independently rebuilt the key from Latin
marginal decipherments. The public open catalogue still lists the item.
The repository's taken list already identifies it as `ferdinand1552`.
I checked the manuscript before consulting that list. The subsequent
GitHub check resolved the discrepancy before transcription or recovery.

- CLAIMANT · [WAINUT's merged recovery](https://github.com/dbourdeau/cyphersolver/pull/224)
  reports a frozen key from the glossed 13 October letter and a reading
  of the unglossed 15 October letter.
- CLAIMANT · [Brice Dudout's independent recovery](https://github.com/dbourdeau/cyphersolver/issues/746)
  reports verification against the glossed 22 October letter.
- PRIMARY · [Ambrosiana G 275 inf.](https://digitallibrary.unicatt.it/veneranda/0b02da828027c8d4).
  The archive served the selected pages. C. 10r visibly has separated
  marginal Latin texts beside cipher blocks. C. 35r visibly has cipher
  in a similar sign repertoire and no gloss on the face inspected.
- SCHOLARLY · [Carpentieri 2012](https://real.mtak.hu/147787/1/478-Article%20Text-1027-1-10-20220716.pdf)
  describes the codex and lists the October 1552 letters.

The published key can support a later calibration with a reserved
gloss. For this dive, the next target must still need a reconstructed key.
