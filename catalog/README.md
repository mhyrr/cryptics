# catalog/

One file per candidate in `entries/<slug>.md`, in the format of `TEMPLATE.md`
(TOML frontmatter between `+++` fences, then markdown). `INDEX.md` is
generated by `scripts/rank.py`; never edit it by hand. `EXCLUDED.md` records
what we considered and left out, with the reason, so nobody re-proposes it.

Workflow for a new entry:

1. Copy `TEMPLATE.md` to `entries/<slug>.md`.
2. Fill it from sources you can cite. Web search or fetch every load-bearing fact.
3. Score against `rubric/RUBRIC.md`. Write the "Why the scores" lines.
4. `python3 scripts/validate.py` then `python3 scripts/rank.py`.

Scores are provisional until a second pass. A second pass on an entry updates
the scores in place and notes the change in a `## Revisions` section at the
bottom of the entry with the date.
