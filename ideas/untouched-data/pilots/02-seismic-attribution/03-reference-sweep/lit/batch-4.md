# Reference sweep — batch 4 (10 detections)

Input: `batch-4-input.tsv`. Method: 2–4 web searches per detection plus WebFetch on the best hit, run 2026-11-10. Search is English-language web only (one Chinese-language query, for 428). The search engine does not honour boolean OR, so the multi-term queries below were in effect keyword bags. "Nothing found" means nothing turned up in these searches. It does not mean nothing happened.

Distances are great-circle estimates from the grid point to the reported coordinates. Where a source gives a place but no coordinates, the coordinates are my approximation and are marked "approx."
